# UI primitives

Locally maintained shadcn/ui-style components using its Radix/Slot, CVA and
Tailwind composition conventions. Button, Card, Badge, Input and Sheet are
adapted for this application; there is no runtime shadcn service or CLI execution.

References: https://ui.shadcn.com/docs/components/radix/button and
https://ui.shadcn.com/docs/components/radix/sheet (shadcn/ui, MIT).
Versions are pinned in package.json; generated components are reviewed source.
