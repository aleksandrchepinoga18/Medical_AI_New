# Стартовый каталог общего медицинского корпуса

Ссылки, даты и опубликованные условия использования сверены 23 ноября 2026 года.
Для материалов MedlinePlus приведена дата обновления, указанная на странице.
Первичная дата публикации там не указана, поэтому при загрузке поле
`publication_date` можно оставить пустым.
